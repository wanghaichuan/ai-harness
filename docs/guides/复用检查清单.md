# 新项目接入 Harness 复用检查清单

复制 `ai-harness/` 骨架到新项目后，逐项核对：

## 必做

- [ ] `CLAUDE.md`：项目身份、模块结构、禁止事项已填实际信息
- [ ] `AGENTS.md`：导航链接指向项目实际 docs
- [ ] `docs/architecture/`：写好架构总览 + 隐性约定
- [ ] `docs/product/`：产品规则与业务边界
- [ ] `docs/standards/`：数据库/测试规范
- [ ] `openspec/changes/`：变更目录就绪，命名用中文；`changes/README.md` 说明保留
- [ ] 数据库脚本执行约定：**由人手动执行，禁止 AI 自行执行**（已写入 CLAUDE.md 禁止事项）
- [ ] CodeGraph：`npm i -g @colbymchenry/codegraph` → `codegraph init` → `codegraph install`（MCP）
- [ ] 记忆体系：`MEMORY.md` 索引建好
- [ ] 护栏：`.claude/hooks/`（写入保护）+ `settings` 权限配置

## 按需

- [ ] 团队 skills（prepare-review / 架构检查 / SQL 检查）拷入 `.claude/skills/`
- [ ] 只读评审 agent 拷入 `.claude/agents/`
- [ ] SVN/git 忽略清单含 `.codegraph/`、`target/`、`logs/`

## 最后

- [ ] 跑一次端到端演练：propose → apply → verify → archive 小变更
- [ ] 确认 codegraph sync + 记忆更新前置动作已写入 CLAUDE.md 且被遵守
