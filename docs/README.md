# docs/ — 知识库结构（模板）

知识库四大类，先显性化再编码：

| 目录 | 内容 | 何时看 |
|------|------|--------|
| `architecture/` | 架构总览、隐性约定 | 怎么跑、为什么这么写 |
| `product/` | 产品规则、业务边界 | 需求是否越界 |
| `standards/` | 数据库/测试/编码规范 | 写 SQL、写测试前 |
| `guides/` | AI 协作指南、业务词索引、技能手册、工具安装 | 人机协作 |

版本化交付物（PRD/接口/库表/测试）放 `versions/<版本>/`，内部按 **需求 / 开发 / 测试** 三类分子目录；另有 `design/` 存原型设计（文件过大过多，**不上传仓库**，提交时注意）。

## 归档归属速查

| 产物 | 去向 |
|------|------|
| 需求 / PRD | `versions/<版本>/需求/` |
| 接口设计 / 库表 / SQL | `versions/<版本>/开发/` |
| 测试用例 / 测试报告 | `versions/<版本>/测试/` |
| 原型设计 | `versions/<版本>/design/`（不上传仓库） |
| 开发记录 / 改造总结 | `records/` |
| 变更工件 | `../openspec/changes/`（完成后进 `archive/`） |
